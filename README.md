# Taskwolf - Workflow

[![CI](https://github.com/taskwolf-net/taskwolf-workflow/actions/workflows/ci.yml/badge.svg)](https://github.com/taskwolf-net/taskwolf-workflow/actions/workflows/ci.yml)

This module implements all the functionalities of the Taskwolf workflow system. One part of this module takes care of the architecture and functionality of the workflows, the other part implements the sub-workflow functionality in the form of special triggers and actions.
